This Repository includes GenAI projects done to explore various use cases of LLMs, evaluate and observe performances.
The libraries used are mostly langchain and langgraph.
This repository also contains the files used as data for the LLM applications.
Most of the code files are Jupyter Notebooks for ease of use and exploration.
The required installations for each of the use-case are mentioned in the respective notebooks (assuming python3 is already installed in the system).
This repository can act as a starting point for POCs.
